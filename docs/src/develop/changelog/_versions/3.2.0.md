## <span class="changelog-version">3.2.0</span><span class="changelog-date">2026-09-20</span>

日期时间能力增强，补齐选择器自定义触发与范围快捷选项；优化表格、颜色选择、反馈组件交互与遮罩视觉。

### 新功能

- **DateRangePicker**：支持 `show-time` 与 `default-time`，面板内切换日期 / 时间并确认写入
- **范围快捷选项**：新增 `range-shortcuts`、`shortcuts-position`，默认提供近 7 天 / 近 30 天 / 近一年，可自定义或关闭
- **自定义触发器**：DatePicker、DateRangePicker、MonthPicker、YearPicker、TimePicker 新增 `#trigger` 插槽，可用按钮等元素唤起面板
- **今日标识**：范围选择日历对「今天」增加圆点提示
- **ColorPicker**：新增 `shape`（`square` / `circle`）、`show-value`（触发器旁展示色值）；`size` 四档尺寸继续可用
- **Table**：新增 `size`（`mini` / `normal` / `large`）控制表格密度
- **ConfigProvider**：支持全局 `fontFamily`，组件字体统一跟随配置
- **Radio 按钮组**：选中项增加滑动指示块过渡
- **Steps / Switch**：状态切换补充过渡动画

### 优化

- **TimePicker / 范围时间**：时间列滚动定位、居中与高亮交互优化
- **Message**：顶部向下、底部向上淡入弹出；底部堆叠改为偏移定位，连续弹出更顺畅
- **遮罩**：Modal、Drawer、Spin 统一为毛玻璃 + 淡黑遮罩，适配深色模式

### 修复

- **Table**：去除末行与表格外框叠加的双边框
- **DateRangePicker**：修复 `defaultTime` 的 TypeScript 类型断言，避免构建报错
