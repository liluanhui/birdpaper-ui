## <span class="changelog-version">3.2.0</span><span class="changelog-date">2026-09-20</span>

Expands date/time capabilities with custom triggers and range shortcuts, and polishes table, color picker, feedback interactions, and overlay visuals.

### Features

- **DateRangePicker**: Adds `show-time` and `default-time`, with in-panel date/time switching and confirm-to-commit
- **Range shortcuts**: Adds `range-shortcuts` and `shortcuts-position`; defaults cover last 7 / 30 days and last year, and can be customized or disabled
- **Custom trigger**: DatePicker, DateRangePicker, MonthPicker, YearPicker, and TimePicker gain a `#trigger` slot for custom openers such as buttons
- **Today marker**: Range calendars show a today indicator dot
- **ColorPicker**: Adds `shape` (`square` / `circle`) and `show-value`; four `size` levels remain available
- **Table**: Adds `size` (`mini` / `normal` / `large`) for density control
- **ConfigProvider**: Supports global `fontFamily` so components follow the configured font stack
- **Radio button group**: Selected item uses a sliding indicator transition
- **Steps / Switch**: Adds transitions for state changes

### Improvements

- **TimePicker / range time**: Improves time-column scroll positioning, centering, and highlight behavior
- **Message**: Top messages fade/slide down, bottom ones fade/slide up; bottom stacking uses offset positioning for smoother consecutive toasts
- **Overlay**: Modal, Drawer, and Spin share a frosted-glass mask with a light dim layer, including dark mode

### Fixes

- **Table**: Removes the double border caused by the last row and the table frame
- **DateRangePicker**: Fixes the `defaultTime` TypeScript prop cast that broke production builds
